# Lifecycle.NET brand assets

The official Lifecycle.NET logo is [`assets/lifecycle-net-logo.png`](../assets/lifecycle-net-logo.png). Use this exact artwork for repository documentation, package pages, the GitHub Pages site, website headers, social previews, and future desktop or framework integration surfaces.

Do not recolor, crop, redraw, or substitute the mark. For NuGet's size limit, `assets/lifecycle-net-package-icon.png` is a lossless downscaled derivative of this approved artwork; all other surfaces use the full official asset.
